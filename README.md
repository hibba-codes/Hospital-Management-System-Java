# Hospital Management System (Java)

This is a simple Java project built using Object-Oriented Programming concepts.

## Features
- Inheritance (Hospital → EmergencyPatient)
- Array of Objects
- Loops
- Conditions
- Methods

## Functionality
- Displays patient information
- Identifies patient type (Child, Teenager, Adult)
- Checks emergency status
- Calculates total hospital earnings

## Learning Purpose
This project was built as a beginner OOP practice project in Java.
